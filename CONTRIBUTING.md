# Contributing

Open an issue describing the scientific or engineering objective, expected output, assumptions, sources, risks and testing criteria. Keep pull requests focused; include tests, documentation and reproduction commands. Use only lawful data and code with appropriate rights. Disclose conflicts and limitations. Never commit credentials or wallet secrets.

The initial repository has no selected open-source license. Do not assume redistribution or reuse rights until the owner publishes a license or grants permission. Contributors must agree on contribution terms before substantive external contributions are accepted.
