# Research and development roadmap (proposed)

| Phase | Deliverable | Acceptance evidence |
| --- | --- | --- |
| 1 | Charter and public project register | Published charter, verified token metadata, named responsibilities, legal feasibility review |
| 2 | Orbit Lab | Reproducible calculations, tests and comparison against published examples |
| 3 | Telemetry simulation | Documented synthetic data, fault detection metrics and reproducible test logs |
| 4 | Robotics simulation | Demonstration in a safe virtual environment, failure cases and review |
| 5 | Corporate formation | Registration and applicable compliance documents, budget and qualified personnel |
| 6 | Ground prototypes | Risk assessment, test protocol, independent review and funding approval |

No deadline or future flight mission is committed. Each phase depends on resources, applicable rules and review. Publish progress with links to evidence; do not mark a phase complete merely because it is proposed.
